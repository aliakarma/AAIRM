# Datasets

AAIRM supports three dataset modes.

## Synthetic (default — no download needed)

Generated by `DemandGenerator` using the paper's data-generating process:
1,200 SKUs, 5 categories, 730-day horizon, seed=42.

```bash
make generate-synthetic
```

## M5 Forecasting Competition

**Source:** Kaggle — `competitions/m5-forecasting-accuracy`  
**License:** Competition-specific terms  
**Size:** ~70 MB

Walmart daily sales for 30,490 product series across 10 stores (2011–2016).
AAIRM selects the top 1,200 SKUs by total sales volume.

**Category mapping:**

| M5 Department | AAIRM Category |
|---|---|
| FOODS_1, FOODS_2 | grocery |
| FOODS_3 | frozen_food |
| HOBBIES_1 | apparel |
| HOBBIES_2 | dry_fruits |
| HOUSEHOLD_1 | cosmetics |
| HOUSEHOLD_2 | dry_fruits |

```bash
# Requires KAGGLE_USERNAME and KAGGLE_KEY in .env
make download-data
make preprocess-data
```

## Corporación Favorita

**Source:** Kaggle — `competitions/favorita-grocery-sales-forecasting`  
**License:** Competition-specific terms  
**Size:** ~370 MB

Ecuadorian supermarket chain, 2013–2017, 33 product families.

## Instacart Market Basket Analysis

**Source:** Kaggle — `competitions/instacart-market-basket-analysis`  
**License:** CC BY-SA 4.0  
**Size:** ~200 MB

Used for trend features (P2) and category co-purchase matrix (P4).
Does **not** produce a demand time-series.

!!! warning
    Raw data files must never be committed to the repository.
    `data/raw/` and `data/processed/` are in `.gitignore`.
