# Data Directory

This directory holds all datasets used in AAIRM experiments.

## Directory Structure

```
data/
├── raw/          ← gitignored; downloaded by scripts/download_datasets.py
│   ├── m5/
│   ├── favorita/
│   └── instacart/
├── processed/    ← gitignored; generated by scripts/preprocess_all.py
└── synthetic/    ← committed seed files (no download needed)
    ├── sku_catalog_seed.csv
    ├── supplier_catalog_seed.csv
    └── demand_params_seed.json
```

**IMPORTANT:** Raw and processed data are never committed to the repository.
Only the small seed files in `data/synthetic/` are version-controlled.

## Datasets

### 1. Synthetic (default — no download needed)

Generated by `DemandGenerator` using the paper's DGP (Section 5.1).
Run: `make generate-synthetic`

### 2. M5 Forecasting Competition

| Field | Value |
|---|---|
| Source | Kaggle: `competitions/m5-forecasting-accuracy` |
| License | Competition-specific |
| Size | ~70 MB |
| Citation | Makridakis, S., et al. (2022). M5 accuracy competition. *International Journal of Forecasting*. |

Required files:
- `sales_train_validation.csv`
- `calendar.csv`
- `sell_prices.csv`

### 3. Corporación Favorita

| Field | Value |
|---|---|
| Source | Kaggle: `competitions/favorita-grocery-sales-forecasting` |
| License | Competition-specific |
| Size | ~370 MB |

Required files:
- `train.csv`, `items.csv`, `stores.csv`, `transactions.csv`, `oil.csv`, `holidays_events.csv`

### 4. Instacart Market Basket Analysis

| Field | Value |
|---|---|
| Source | Kaggle: `competitions/instacart-market-basket-analysis` |
| License | CC BY-SA 4.0 |
| Size | ~200 MB |
| Usage | Trend features for P2 and co-purchase matrix for P4 only |

Required files:
- `orders.csv`, `order_products__prior.csv`, `products.csv`, `departments.csv`

## Download Instructions

```bash
# Add Kaggle credentials to .env:
KAGGLE_USERNAME=your_username
KAGGLE_KEY=your_api_key

# Download all datasets:
make download-data

# Preprocess:
make preprocess-data
```
